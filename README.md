# 클래스노트 출석 체크
학생 이름을 등록하고 날짜별 출석, 지각, 조퇴, 결석을 기록하는 반응형 웹앱입니다.
## 실행
`index.html`을 최신 브라우저에서 열면 바로 사용할 수 있습니다. 별도 설치나 빌드 과정은 없습니다.
## 사용 방법
- **학생 추가**에서 이름을 한 줄에 한 명씩 입력하거나 쉼표로 구분해 등록합니다.
- 날짜를 선택하고 학생별 출석 상태를 지정합니다. **전체 출석**으로 한 번에 체크할 수도 있습니다.
- 검색으로 학생을 찾고, **출석부 내보내기**로 해당 날짜의 기록을 CSV로 저장합니다.
- 명단과 출석 기록은 현재 브라우저의 로컬 저장소에 저장됩니다. 다른 브라우저나 기기와 자동으로 동기화되지 않습니다.
